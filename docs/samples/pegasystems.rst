Details of my involvement
-------------------------

Developers owned all documentation before I joined, including guides and Readmes. The guides were MS Word files; the Readmes were markdown files, packaged with the product code in Git repos. There are separate Constellation SDKs and Traditional Starter Packs for Angular, React, and Vue. So, I practically owned the documentation for **7 products**. 

Starting with the React SDK guide, I rewrote the structure for better flow (product overview > prerequisites > installing and configuring dependencies, etc.). With the structure approved, I improved the language and made it more consistent. My primary focus in this step was to simplify complex procedures. Finally, I made accessibility improvements like high-contrast screenshots, alt-text, and standardized font sizes.

Each change went through a detailed review with the developer and project manager. During these meetings I also explained the rationale for each change and rewrite. This ensured stakeholder buy-in and support.

The React SDK Readme followed suit. New structure, improved and simplified language, and improvemed accessibility.

The approved guide and Readme became the template. I implemented these templates in the Angular and Vue SDK guides and Readmes. 

By now, the stakeholders understood my process, approach, and priorities. So,  creating the Traditional Starter Packs documentation was quicker.
